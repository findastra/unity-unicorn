# Udon kits and the compose-a-world-from-kits trick (0.5.4-20261026)

- **What changed:** a new world tool, `udon-kit-mover` (`scripts/udon-kits/`): eight Udon kits (doorspace-door,
  teleport-pad, glass-animal-collectible, toggle-switch, synced-counter, timed-respawn, audio-zone, quest-checklist),
  each a pure C# core plus an UdonSharp wrapper; the kit manifest `scripts/udon-kits/udon-kits-manifest.json` with a
  fixed id vocabulary; 29 headless core and parity tests (`dotnet run --project scripts/udon-kits/Tests -c Release`); the
  manifest and UdonSharp limits gate (`test/udon-kits-test-20261026.mjs`); a GitHub Actions workflow that runs them on
  push (`.github/workflows/udon-kits-20261026.yml`); an idempotent installer for a world
  (`scripts/udon-kits/Tools/install-udon-kits-20261026.ps1`); the guide `docs/udon-kits-20261026.md`. A new trick,
  `compose-a-world-from-kits` (`skills/compose-a-world-from-kits/SKILL.md`): compose world behaviour only from manifest
  kits, run the tests, playtest, and repair at most 3 times before rolling back. Registered in `pet.json` (L1 tools,
  world side; L2 tricks), on the page (TOOLS_MAIN, TRICKS, Native tools · 86), in `docs/tool-categories-20261024.json`
  (mover, whole world) and `docs/made-by-20261019.json`, and in `tools/udon-kit-mover-20261026.json`.
- **Also:** this repo now records changes in `changes/` (AGENTS.md and CLAUDE.md say so), as the hub's AGENTS.md asks of
  pet repos with their next pull request.
