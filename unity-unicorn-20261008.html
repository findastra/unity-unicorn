                      Your Unity tool library

                      Keep the tools you already have together, with the last recorded time each was used. Import a private catalog to add local paths and history, then import a completed report after running a tool.

                      How to use this library
                      1. Import a catalog with your existing tools, local paths and dated execution evidence. Dates that cannot be established stay Unknown.
                      2. Open a tool's command details and copy the command. Replace placeholders, check the project and output paths, then run it in the appropriate terminal or the already-open Unity editor.
                      3. Import the generated report or usage log. File modification dates are not execution evidence; this library uses the completion time in the imported record.

                      Opening this page, importing a catalog, copying a command and exporting a backup never mark a tool as used. This browser has no connection to Unity and cannot run commands. Private paths, reports and history stay in this browser until you export them.

                      Your connections. Run tools locally, then import their reports into the tool library. Unity and VRChat are not directly connected to this browser.
