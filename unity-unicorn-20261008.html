unity-stable-quick-summary

Unity Stable is the pet program run by you and Unity Unicorn. It is a dashboard that presents the health of, and organizes, your world and avatar programs and the tools and tricks used to manage them, which are always created with the intention of preserving the authenticity, creativity and provenance of all artists' work.

                              Send to

                              What the button does: it saves a small job file, unity-unicorn-vine-spawn-<world>-<time>.json, to your Downloads, with your colours and settings.

                              What happens in Unity: in the chosen world's Unity editor, the tool looks in Downloads every 2 seconds. It opens its window with your colours and flashes Unity on the taskbar. Nothing grows until you select the walls, arches or railings there and press Grow vines; one Undo takes them away.

                              What a web page can't do: it can't start Unity, open a project, bring Unity to the front or write into a project folder. So that world has to be open in Unity, with the tool installed once: copy scripts/unity-editor/vine-spawn-with-trumpet-flowers-20261019.cs into its Assets/UnityUnicorn/Editor/. If the world isn't open, open it; the job waits in Downloads for 2 hours.

                              If your browser saves downloads to another folder, press Also watch a folder… in the tool's window (Tools › Unity Unicorn › vine-spawn-with-trumpet-flowers). Jobs for another world are left for that world's editor.

                              Built on vine-bloomer (the Blender ivy mantle of Piranesi House). This one grows single vines in Unity over the objects you pick, with leaves, buds and five-lobed trumpet flowers, and its own Unity Stable/Vine Bloom shader. Your colours and world stay in this browser.

                                              Your Unity tool library

                                              Keep the tools you already have together, with the last recorded time each was used. Import a private catalog to add local paths and history, then import a completed report after running a tool.

                                              How to use this library
                                              1. Import a catalog with your existing tools, local paths and dated execution evidence. Dates that cannot be established stay Unknown.
                                              2. Open a tool's command details and copy the command. Replace placeholders, check the project and output paths, then run it in the appropriate terminal or the already-open Unity editor.
                                              3. Import the generated report or usage log. File modification dates are not execution evidence; this library uses the completion time in the imported record.

                                              Opening this page, importing a catalog, copying a command and exporting a backup never mark a tool as used. This browser has no connection to Unity and cannot run commands. Private paths, reports and history stay in this browser until you export them.

                                              Your connections. Run tools locally, then import their reports into the tool library. Unity and VRChat are not directly connected to this browser.
