## 8. Working on Astra's PC

- Windows file dialogs only accept typing in the *File name* box. Move between folders by double-clicking or using the dialog's up arrow.
- Pause and ask if the selection or editor mode changes without an action, because Astra may be clicking too.
- Some windows (PowerToys Peek, Explorer, browsers) can't be controlled. Ask Astra to close them.
- Folder-access prompts appear in the Claude app and time out if nobody answers them.

## 10. my-preferred-nomenclature

Use lowercase filenames with hyphens instead of spaces. Append the owner's America/Denver creation date immediately before the extension: `<descriptive-name>-YYYYMMDD.<extension>`. When a time is needed, use `<descriptive-name>-YYYYMMDD-HHMMSS.<extension>` with a 24-hour clock. Audit every new file and update affected references before delivery.

Tool cards use their real dated definition filename, such as `no-windows-audit-tool-20261011.json`, with a concise two-sentence description underneath. Executable scripts follow the same naming rule. Keep the definition date separate from the evidence-backed last execution date. Stable Unity class names, asset GUID references and imported legacy source paths are not tool-definition names; do not rename those blindly. If a new reserved filename is required, explain the conflict before creating it.

## 11. Open arches and free water passages

Check all architectural materials, including glass, metal and marble. Sample low openings down to the floor, verify the curved arch head, and test the assembled scene and cooked colliders. Remove obsolete window-seat interactions when their benches are removed. A real water channel may retain its documented bed and side walls; verify a separate clear flow path above the bed rather than deleting useful supports. This is a geometry check, not a fluid simulation.
