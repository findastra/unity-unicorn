# Unity Unicorn skill book · 2026-10-09

This file sorts what Unity Unicorn has learned about Astra's avatar and world work into skill categories. Each skill has a status: **learned** (done successfully at least once), **in progress** or **planned**. Add new skills to the right category and log each session at the bottom.

Private details stay out of Git: no account emails, passwords, blueprint IDs, exported records or machine paths. Folders are described by role, not by full path.

## 1. Project finding and versioning

| Skill | Status | How |
|---|---|---|
| Find the newest version of an avatar | learned | Compare *date modified*. Dated folders in the asset library (`poppy-4-5-26/`) are scene backups, and the real Unity project is the folder that has `Assets/`, `Packages/` and `ProjectSettings/`. Byte-compare scenes when the names look alike. |
| Read the avatar's edit log first | learned | Each avatar's asset folder has `Edit Log - <name>-<date>.txt/.md` with variants, done and to-do lists. |
| Map the objects in a scene without opening Unity | learned | Parse the scene YAML. `PrefabInstance` blocks give the object name (`m_Name` override), its parent (`m_TransformParent`) and the source prefab GUID. |

## 2. Uploading avatars (VRChat SDK)

| Skill | Status | How |
|---|---|---|
| Open a project from the external drive | learned | Add it in Unity Hub and VCC with *Add Existing Project*. The first open takes about 5–8 minutes. |
| Upload a new version | learned | SDK → Builder: pick the avatar, enter the name (with a version bump), set Visibility to Private, then *Capture In Scene* → *Capture* for the thumbnail and *Build & Publish*. Shader compiling and upload take about 5–10 minutes. |
| Upload to the right account | learned | Astra signs in herself. If the saved blueprint ID belongs to another account, the SDK clears it and creates a new avatar. |
| Copyright agreement | learned | Always ask Astra before clicking OK. |

## 3. Diagnosing failed builds

| Skill | Status | How |
|---|---|---|
| Read the console | learned | Show errors only and read from the start of the failed build. |
| "Prefab with a missing script" | learned | Select the named object. "(Script) can not be loaded" means a package is missing, so check the gimmick's folder name (`*_MA_*` means Modular Avatar). Install the package, or tag the object EditorOnly. |
| "Download size over 200 MB" | learned | The alert can be stale from an older build, so rebuild first. If it's real, reduce the largest textures (normal maps and 4K base colours). |
| Post-failure NullReference in the SDK panel | learned | Noise; it clears after a successful build. |

## 8. Working on Astra's PC

- Windows file dialogs only accept typing in the *File name* box. Move between folders by double-clicking or using the dialog's up arrow.
- Pause and ask if the selection or editor mode changes without an action, because Astra may be clicking too.
- Some windows (PowerToys Peek, Explorer, browsers) can't be controlled. Ask Astra to close them.
- Folder-access prompts appear in the Claude app and time out if nobody answers them.
