# menu-map

The first panel from [panel-ideas-20261019.md](panel-ideas-20261019.md). Poppy sits at 256 of 256 synced parameter bits
after VRCFury's compressor, so every new effect needs a plan: where it goes in the menu and what it costs. The menu you
set up in Unity is not the menu you get in VRChat. VRCFury and Modular Avatar add their pages and parameters at build
time, and VRCFury's compressor folds parameters together. menu-map shows the built result.

## In Unity: Tools › Unity Unicorn › menu-map

`scripts/unity-editor/menu-map-20261019.cs` (copy it into `Assets/UnityUnicorn/Editor/`). Select the avatar (any object
under its VRC Avatar Descriptor) and run the menu item. It:

1. makes a test copy of the avatar with `Instantiate` and unpacks its prefabs, the way VRCFury's own play-mode build does;
2. runs `VRCBuildPipelineCallbacks.OnPreprocessAvatar` on the copy, the same build step an upload runs, so VRCFury,
   Modular Avatar and NDMF build their menus, parameters and compressor into it;
3. reads the built expression menu (every page, control name, control type, parameter, value, sub-parameters, puppet
   labels and icons) and the built parameters (type, synced, saved, bits, and the menu path that uses each one);
4. reads the total with `VRCExpressionParameters.CalcTotalCost`, the total before the compressor from VRCFury's
   "Parameter Compressor" debug note, and your own parameters' total before the build;
5. deletes the copy (`DestroyImmediate`, in a `finally`) and writes
   `UnityUnicornReports/menu-map-<avatar>-<time>.json`, then a usage receipt `menu-map-receipt-<time>.json`
   (`unity-unicorn.tool-usage/v1`) for the tool library.

Nothing on the avatar changes and the scene is never saved. Unity may still mark the scene as changed because a copy
was made and deleted; you can leave that unsaved or save it, nothing is different. Icons are drawn through a
RenderTexture at 64 px and stored as PNG in the file, so compressed or unreadable icons still come out. The SDK is
reached by reflection, so the script compiles in the Unity Unicorn assembly without SDK references.

For agent queues and scripts, `UnityUnicorn.MenuMap20261019.ExportAvatar("<avatar name>")` does the same for an avatar in
the open scene and returns the file's path.

## On the page: unity-unicorn-menu-map-tool-panel

- **Load a menu map**: pick the JSON from Unity. It stays in that browser tab; nothing is uploaded or saved.
- **Try the sample**: [menu-map-sample-20261019.json](menu-map-sample-20261019.json), a made-up avatar.
- The radial menu: one wedge per control, starting at the top and going clockwise like VRChat's. Click a submenu to go
  in, the middle to go Back. Toggles light up pink when you switch them (in the page only). The line below says what the
  control is, which parameter it drives, its type, its bits and whether it is saved.
- The parameter budget: bits used out of 256 (red when over), free bits, the total before VRCFury's compressor and before
  the build, and a coloured bar split by add-on. An add-on is the top menu that uses a parameter (Outfits, Effects …);
  VRCFury's compressor slots (`SyncIndex`, `SyncDataNum`, `SyncDataBool`) are their own row; the rest is "Not in the menu"
  (face tracking, OSC and the like). When a compressor ran, a menu parameter that is not synced was most likely folded
  into it, and its bits before folding are shown as "folded".
- **Every parameter** lists all of them with type, bits and menu path.

Everything is drawn with `createElement`, `createElementNS` and `textContent`; strings from the file are clipped, icons
are only accepted as `data:image/png;base64`, and nothing is written as HTML.

## The file: unity-unicorn.menu-map/v1

```
{ "schema": "unity-unicorn.menu-map/v1", "tool_id": "menu-map", "avatar": {"name": …}, "built_at": …, "unity": …,
  "menu": {"name": …, "controls": [{"name", "type", "parameter", "value", "icon", "sub_parameters"?, "labels"?,
                                    "submenu"? (a page; "loop": true when it links back up)}]},
  "parameters": [{"name", "type": "Bool|Int|Float", "synced", "saved", "default", "bits", "menu_path"}],
  "budget": {"limit": 256, "used", "before_compressor" (or null), "before_build"},
  "icons": {"i0": "data:image/png;base64,…"} }
```

Control types: Button, Toggle, SubMenu, TwoAxisPuppet, FourAxisPuppet, RadialPuppet. A menu map of a real avatar holds
the names and icons of its paid assets: keep it on your PC, never in this repository.
